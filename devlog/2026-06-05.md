# 개발일지 — 2026년 6월 5일

## 작업 요약

환자 검색 기능 전면 개편 및 UI/텍스트 전반 개선

## 주요 변경 사항

### 1. 환자 검색 — 모달 → 전용 페이지 전환

**변경 전:** 팝업 모달(`PatientSearchModal`) 방식  
**변경 후:** `/search` 전용 라우트 페이지(`PatientSearchPage`)

- `SearchProvider`의 `openSearch()`가 `navigate('/search')`로 동작하도록 변경
- 기존 모달 호출 코드(`openSearch()`) 수정 없이 모든 페이지에서 자동 전환
- 페이지 레이아웃: 모바일 `PageHeader` + `BottomNav`, 데스크탑 사이드바 포함 일반 페이지

### 2. 사이드바 — 환자 검색 탭 통합

- 환자 검색을 구분선 아래 별도 섹션 → 네비게이션 탭 목록 안으로 통합
- 데스크탑에서 다른 탭과 동일한 스타일로 표시, 활성 상태 하이라이트 적용
- 탭 순서 조정: `문의함`을 최하단으로 이동 (환자 검색 아래)

**역할별 최종 탭 순서 (데스크탑 사이드바):**

| 선생님 | 대표 | 관리자 |
|---|---|---|
| 홈 | 대시보드 | 대시보드 |
| 결제/건수 | 결제/건수 | 건수현황 |
| 월별현황 | 건수현황 | 직원관리 |
| 환자 검색 | 직원관리 | 환자 검색 |
| — | 환자 검색 | 문의함 |
| — | 문의함 | — |

### 3. 모바일 — 각 페이지 헤더에 검색 아이콘 추가

바텀 네비 검색 탭 방식 대신, 모든 주요 페이지 헤더 우측에 돋보기 아이콘 추가

| 페이지 | 방식 |
|---|---|
| 선생님 대시보드 | 커스텀 헤더 내 `lg:hidden` 아이콘 |
| 대표 대시보드 | 커스텀 헤더 내 `lg:hidden` 아이콘 |
| 결제/건수 | `PageHeader showBack showSearch` |
| 월별현황 | `PageHeader showSearch` (기존 유지) |
| 건수현황 | `PageHeader showSearch` (기존 유지) |
| 직원관리 | `PageHeader showSearch` 추가 |
| 문의함 | `PageHeader showSearch` 추가 |

### 4. 검색 조건 강화

- 기존: 1글자 이상 입력 시 검색
- 변경: **2글자 이상** 입력 시 검색 (`queries.ts` `enabled` 조건 + UI 분기)
- 0글자: "두 글자 이상 입력하면 검색합니다"
- 1글자: "한 글자 더 입력해주세요"

### 5. 월 선택 UI 개선

- 기존: `<input type="month">` 네이티브 인풋 (모바일에서 잘 안 보임)
- 변경: 파란 버튼 클릭 → 기존 `MonthPicker` 팝업 (연도/월 그리드 선택)

### 6. 문의함 — 관리자 조치완료 기능 추가

- `Inquiry` 타입에 `is_resolved: boolean` 필드 추가
- 관리자(`admin`) 계정에만 각 문의 카드에 `조치완료` 버튼 표시
- 조치완료 시 해당 문의를 하단 "조치완료" 섹션으로 분리, 흐리게 표시 + `완료` 뱃지
- 대표(`director`)는 버튼 없이 조회만 가능

> **DB 마이그레이션 필요:**
> ```sql
> ALTER TABLE inquiries
>   ADD COLUMN IF NOT EXISTS is_resolved boolean NOT NULL DEFAULT false;
> ```

## 버그 수정

### Sidebar null 참조 크래시 (콜드 로드 시)

- **문제:** `user.role === 'director'` 코드가 `if (!user) return null` 보다 앞에 위치해 앱 초기 로딩 시 `TypeError` 발생 가능
- **수정:** `user?.role` optional chaining 적용

### 로그아웃 시 PHI 캐시 잔류

- **문제:** 로그아웃 후 30초 이내 다른 계정 로그인 시 이전 계정의 환자 검색 결과가 노출될 수 있음
- **수정:** `SIGNED_OUT` 이벤트 시 `queryClient.removeQueries({ queryKey: ['patientSearch'] })` 추가
