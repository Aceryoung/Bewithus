## 변경 사항

### 1. 웨일 브라우저 네비게이션 버튼 오작동 수정

**문제:** 웨일 브라우저에서 `‹` `›` 문자로 만든 이전/다음 달 버튼이 동작하지 않음
**원인:** 웨일 브라우저의 마우스 제스처 기능이 `‹`(U+2039), `›`(U+203A) 유니코드 문자를 브라우저 뒤로/앞으로 제스처로 인식하여 클릭 이벤트를 가로챔
**해결:** 해당 문자를 SVG chevron 아이콘으로 교체 — Chrome, Safari, 모바일 등 모든 환경에서 정상 동작 확인

**수정 파일:**
- `src/components/ui/CalendarView.tsx`
- `src/components/ui/MonthPicker.tsx`
- `src/pages/teacher/MonthlyViewPage.tsx`
- `src/pages/director/DirectorRecordsPage.tsx`

---

### 2. 월 선택 팝업(MonthPicker) 추가

캘린더와 월별 건수 탭에서 월 제목 클릭 시 연도·월을 자유롭게 선택할 수 있는 팝업 추가

- 새 공통 컴포넌트 `MonthPicker.tsx` 신규 생성
- 적용 위치: 대시보드 캘린더, 선생님 월별 건수, 대표 건수 현황(월별 탭)
- 내부적으로 연도 상태를 별도 관리하여 확정 전까지 현재 선택에 영향 없음

---

### 3. 달력 날짜 클릭 → 건수 입력 연동

- 기록이 없는 날짜도 클릭 가능하도록 변경 (기존: 기록 있는 날만 클릭 가능)
- 날짜 클릭 시 `DayRecordsSheet` 팝업 노출, "건수 입력하기" 버튼으로 해당 날짜를 URL 쿼리(`?date=YYYY-MM-DD`)로 전달
- `PaymentPage`에서 `useSearchParams`로 날짜를 읽어 입력 폼 초기값으로 설정
- 대표(director) 역할도 동일하게 건수 입력 버튼 노출

### 4. DayRecordsSheet 팝업 방식으로 통일

- 기존 모바일 바텀시트 / 웹 팝업 분기 제거 → 모든 환경에서 화면 중앙 팝업으로 통일
- 콘텐츠 영역 `max-h-[50dvh]` + `overflow-y-auto` 적용으로 긴 목록도 스크롤 처리
- 버튼이 화면 밖으로 밀리던 문제 해결 (`flex-1` 제거 → 버튼 컨테이너 `shrink-0` 고정)
