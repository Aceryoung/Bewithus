## 버그 수정

### ERR-101 — 건수/결제 저장 실패 (박승용 선생님 제보)

**문제:** 건수 또는 결제 저장 시 ERR-101("건수 저장에 실패했습니다.") 발생

**원인 분석 과정:**
1. Supabase Postgres 로그 확인
2. 해당 시간대 에러: `new row for relation "records" violates check constraint "records_session_count_check"`
3. DB 제약 조건 확인: `session_count >= 0.5 AND session_count <= 16`
4. UI 코드 검토 결과 하한(`Math.max(0.5 또는 1, ...)`) 처리는 있었으나 **상한 처리 누락**
5. 횟수 입력 필드에 `max` 속성이 없어 16 초과 값 입력 시 그대로 DB에 전달됨

**수정 내용:**

| 파일 | 수정 내용 |
|------|----------|
| `src/components/ui/RecordFormFields.tsx` | `Math.min(16, ...)` 추가, `max={16}` 속성 추가 (일반/0.5단위 입력 모두) |
| `src/pages/teacher/PaymentPage.tsx` | `Math.min(16, ...)` 추가, `max={16}` 속성 추가 (건수 탭 일반/0.5단위 입력 모두) |

**수정 전:**
```js
const n = Math.max(1, Math.round(Number(e.target.value) || 1))
```
**수정 후:**
```js
const n = Math.min(16, Math.max(1, Math.round(Number(e.target.value) || 1)))
```
