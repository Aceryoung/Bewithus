로그인 & 기본 설정

1.1 PIN 로그인 순서

아이디·비밀번호 없이 호점 선택 → 이름 선택 → PIN 4자리 순서로 간편하게 로그인합니다.

1
호점 선택

본인이 근무하는 호점(1호점 또는 2호점)을 탭합니다.

2
이름 선택

드롭다운 목록에서 본인 이름을 찾아 선택합니다.

3
PIN 4자리 입력

화면의 숫자 키패드로 PIN을 누릅니다. 4자리를 모두 입력하면 자동으로 로그인됩니다.

4
역할별 화면으로 자동 이동

선생님 → 홈 화면, 대표/관리자 → 대시보드

⚠️ 처음 로그인 시 초기 PIN(0000)으로 로그인하면 새 PIN 설정 화면이 나타납니다. 0000이 아닌 4자리 PIN을 새로 설정해야 합니다.
⚠️ 5회 연속 오류 시 30초 잠금됩니다. 잠금이 풀린 후 다시 시도하세요.

1.2 PIN 번호 변경

로그인 후 홈 화면 우상단의 "PIN 변경" 버튼을 눌러 변경할 수 있습니다.

1
홈 우상단 "PIN 변경" 탭
2
새 PIN 4자리 입력 + 한 번 더 확인 입력
3
"PIN 변경하기" 버튼 탭

오류 발생 시 & 문의함

6.1 오류 발생 시 (선생님)

오류가 발생하면 에러코드가 포함된 문의하기 창이 자동으로 열립니다.

1
문의 창 자동 오픈

에러코드가 메시지 입력창에 자동으로 입력되어 있습니다.

2
어떤 상황에서 오류가 났는지 추가 작성

예) "홍길동 건수 저장하려다 오류가 났어요"

3
"전송" 클릭

담당자에게 이메일로 즉시 발송되며 문의함에도 기록됩니다.
